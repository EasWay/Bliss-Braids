# Bliss Braids

E-commerce website for Bliss Braids hair salon. Online booking, product catalog, and customer management.

## Features

- **Product Catalog** -- Browse and shop hair products
- **Online Booking** -- Schedule salon appointments
- **Customer Management** -- User accounts and order history
- **Responsive Design** -- Works on all devices
- **Modern UI** -- Clean, professional design

## Tech Stack

- **Framework:** Next.js
- **Styling:** Tailwind CSS
- **Language:** TypeScript

## Getting Started

```bash
# Clone the repository
git clone https://github.com/EasWay/Bliss-Braids.git

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm run start` | Start production server |
